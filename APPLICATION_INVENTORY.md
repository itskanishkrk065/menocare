## 1. Top-Level Architectural Overview

MenoCare is an AI-assisted clinical menopause symptom tracking, local lab report analyte extraction, longitudinal time-series analytics, and clinical decision support platform built for midlife women's health.

### Technology Stack
- **Backend**: FastAPI 0.110+, SQLAlchemy 2.0 (asyncio + asyncpg / aiosqlite), Pydantic v2, ReportLab 5.1 (PDF generation), PyTesseract + pdfplumber (local OCR), Google Gemini 1.5 Flash (clinical narrative summarization with deterministic clinical fallbacks).
- **Frontend**: React 18, Vite 5.4, Tailwind CSS with custom Stitch Warm Health design system (`ivory`, `cream`, `sage`, `teal`, `peach`, `charcoal`, `oat`, `lavender`), Lucide React icons, Recharts (time-series, area, radar, and bar charts).
- **Data Isolation & Security**: JWT Bearer token authentication, role-based access control (`patient` vs `doctor`), server-side DPDPA / HIPAA authorization checks (`PatientDoctorAccess`), password hashing via Argon2 / bcrypt.
